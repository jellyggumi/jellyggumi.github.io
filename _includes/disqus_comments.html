{% comment %} Disqus embed, guarded on an actual shortname being configured. As shipped this was the vendor's copy-paste template with the placeholders still in it: it loaded `//yourproject.disqus.com/embed.js` — a forum that does not exist — and set `this.page.url = PAGE_URL` and `this.page.identifier = PAGE_IDENTIFIER`, two undefined identifiers that throw a ReferenceError as soon as Disqus calls the config function. It never fired only because every post carries `comments: false`. Setting one post to `true` would have loaded a broken third-party script and thrown console errors on that page. Now it requires `comments.disqus.short_name` in _config.yml to be set, which it is not, so nothing renders and nothing can break.
